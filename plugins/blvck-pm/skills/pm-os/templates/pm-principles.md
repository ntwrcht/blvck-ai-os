# PM Principles

How I make product decisions. Claude applies these when drafting or challenging any artifact.

1. **Outcomes over output.** A shipped feature that moves no metric is a cost, not a win.
2. **Evidence before conviction.** User quotes, funnel numbers, or support volume — name the evidence or mark the assumption.
3. **The NSM is the tiebreaker.** When two options compete, pick the one with the clearer causal path to the North Star Metric.
4. **Write the objection first.** Every proposal names the strongest argument against it before asking for a decision.
5. **Small bets, explicit kill criteria.** Prefer the reversible version; state in advance what result kills it.
